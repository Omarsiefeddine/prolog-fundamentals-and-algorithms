# prolog-fundamentals-and-algorithms
# Prolog Fundamentals & Logic Functions

A collection of classic Prolog predicates and logic functions demonstrating declarative programming principles, recursive data structure handling, arithmetic processing, and basic search algorithms.

## Included Modules & Predicates

### List Operations
* **`print_list/1`**: Recursively prints each element of a list.
* **`sum/2`**: Computes the sum of all elements in a numerical list.
* **`increment/2`**: Maps a list to a new list where each element is incremented by 1.
* **`list_member/2`**: Determines if an element exists within a list.
* **`list_append/3`**: Appends an element to a list if it is not already present.
* **`max/2` & `maxi/3`**: Finds the maximum numerical value in a given list using helper comparison predicates.

### Math & Control Logic
* **`factorial/2`**: Calculates the factorial of a non-negative integer recursively.
* **`horizontal_star/1`**: Generates a sequence of asterisks based on an integer count.
* **`calc/0`**: Demonstrates standard arithmetic operators (`+`, `-`, `*`, `/`, integer division `//`, exponentiation `**`, and modulus `mod`).
